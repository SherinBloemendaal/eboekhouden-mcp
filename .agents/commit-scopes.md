# Commit scopes

| Scope | Covers |
|-------|--------|
| `app` | Tauri shell: windows, tray, panel, commands, config, icons |
| `mcp` | The MCP server, its tools and its HTTP security |
| `auth` | Accounts, credential stores, sign-in and sessions |
| `log` | Request log and Dashboard figures |
| `ui` | Vue screens, components and styles |
| `release` | Updates, signing, release workflow |
| `docs` | README, roadmap and other docs |
| `deps` | Dependency updates |
| `ci` | CI configuration |
